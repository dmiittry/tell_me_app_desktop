# Tell Me

Программа для Windows 10/11: заметки во вкладках, естественные русские голоса и шкала времени для перемотки.

## Запуск

- Если установлен 64-разрядный Python 3.12 или новее: сначала выполните `python -m pip install -r requirements.txt`, затем откройте `start.cmd` или запустите `python app.py`.
- Запустите новую сборку `dist\TellMe_v7.exe`. Python на целевом ПК не нужен.

Перед запуском новой версии закройте старое окно. Заметки откроются автоматически.

Текст сохраняется автоматически в `%APPDATA%\TellMe\notes.json`. Чтобы перенести заметки на другой ПК, скопируйте этот файл.

## Использование

- `+ Заметка` создаёт вкладку. Есть переименование и удаление.
- Панель текста работает с открытой вкладкой: `Очистить` очищает текст (отмена через Ctrl+Z), `Вставить` вставляет текст из буфера у курсора или заменяет выделение, `Скопировать` копирует весь исходный текст заметки, включая ссылки.
- Ctrl+V и Shift+Insert вставляют текст; Ctrl+C/Ctrl+X работают с выделением, Ctrl+A выделяет всё, Ctrl+Z отменяет изменение, Ctrl+Y или Ctrl+Shift+Z повторяют его. Сочетания Ctrl работают и в русской раскладке. Вставка из караоке возвращает редактор. Пустой или недоступный буфер не изменяет заметку.
- Вставьте текст: озвучка активной заметки сразу начнёт готовиться в фоне, без звука. При наборе подготовка начинается после паузы в полсекунды. Настройка `Готовить звук автоматически` включена по умолчанию и сохраняется между запусками.
- Нажмите `Читать`, когда захотите слушать: кнопка использует готовую запись или подключается к её текущей загрузке без повторного запроса. Если выделен фрагмент, читается только он.
- При чтении открывается караоке: крупный текст, подсветка произносимого слова и автоматическая прокрутка. Кнопка `К тексту` возвращает редактор; переключатель `Караоке` открывает его снова. Подсветка следует за перемоткой, паузой и скоростью проигрывания.
- Для новых записей Дмитрия и Светланы время каждого слова приходит от службы голоса и сохраняется вместе с WAV. Для старых записей без этих данных и голосов Windows используется приблизительная подсветка, что отмечено в окне караоке.
- Автоподготовка работает для выбранной вкладки. После изменения текста или голоса готовится новая запись. Переход на другую вкладку останавливает текущую работу и подготавливает выбранную заметку. `Стоп` отменяет подготовку; сама она не перезапускается до следующего изменения текста, голоса или выбора вкладки.
- В меню `Голос` доступны естественные русские голоса Дмитрий и Светлана, а также голоса Windows для работы без интернета.
- Нейроголоса используют службу Microsoft Edge: при включённой автоподготовке текст отправляется в интернет после вставки или редактирования. Голоса Windows создают звук локально. Автоподготовку можно отключить переключателем в верхней панели.
- Нейроголоса читают потоком: первые пришедшие аудиопакеты сразу декодируются и поступают в проигрыватель, пока остальная запись загружается. Запуск зависит от интернета и службы голоса. При задержках сети программа ждёт продолжения, сохраняя порядок звука.
- Во время подготовки звук играет со скоростью 1×; громкость можно менять сразу. Пауза останавливает прослушивание, а загрузка и сохранение продолжаются. «Стоп» отменяет и загрузку, и прослушивание.
- После подготовки всего текста доступна полная запись WAV. Ползунок времени и кнопки `−10 с`/`+10 с` перематывают её; скорость меняется без повторного синтеза. При скорости 1× поток продолжает играть без переключения после сохранения. При перемотке или изменении скорости проигрыватель открывает готовый файл с текущего места.
- Голоса Windows без интернета по-прежнему готовят текст частями примерно по 25–30 слов и объединяют их в WAV.
- Записи сохраняются в `%APPDATA%\TellMe\audio` и остаются после закрытия программы. Повторное чтение того же текста тем же голосом использует сохранённый файл, в том числе без интернета. Кнопка `Папка записей` открывает эту папку; `Сохранить WAV как…` копирует готовую запись в выбранное место.
- Кнопки `Пауза`, `Продолжить` и `Стоп` управляют чтением.
- Ссылки подчёркнуты; щелчок открывает их в браузере. При озвучивании адрес заменяется словами «Это ссылка». Кнопка `Что будет прочитано` показывает точный подготовленный текст.

Для воспроизведения требуется компонент Windows Media Player Legacy. Если он отключён, включите его в дополнительных компонентах Windows.

## Сборка EXE

На Windows с Python: `python -m pip install -r requirements.txt pyinstaller`, затем `build.cmd`. Готовый файл появится в `dist\TellMe_v7.exe`.

Для изолированной установки: `python -m venv .venv`, затем `.venv\Scripts\python.exe -m pip install -r requirements.txt pyinstaller`. Если окружение `.venv` существует, `start.cmd` и `build.cmd` используют его.

## Проверка разработки

- `python -m unittest -v` — автономные проверки текста, потокового звука, паузы, отмены, сохранения и перемотки.
- `python verify_streaming.py` — проверка реального онлайн-голоса и звукового устройства Windows с временными файлами и выключенной громкостью.
- Для входящего MP3 используется [пакетный декодер PyAV](https://pyav.basswood.io/docs/stable/api/codec.html), для звукового устройства — miniaudio. RAM-буфер проигрывания ограничен двумя секундами; остальной PCM хранится во временном файле. Завершённая запись сохраняется атомарно и повторно используется старым и новым проигрывателем.

Описание проекта, архитектуры, хранения данных и проверок: [документация](docs/README.md).

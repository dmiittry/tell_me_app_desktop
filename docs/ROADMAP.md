# Возможные улучшения

Следующие пункты являются предложениями, а не реализованными возможностями:

- Контекстное меню редактора для вставки, копирования и отмены через правую кнопку мыши.
- Проверка приложения на Windows 10 и дополнительных раскладках клавиатуры.
- Защита от одновременной записи заметок двумя экземплярами приложения.

Изменения архитектуры, хранения данных и безопасности требуют согласования с пользователем.

# Хранение данных

SQL-базы нет. Заметки и настройки сохраняются в `%APPDATA%\TellMe\notes.json`.

Основные поля: `version`, `notes` (объекты с `id`, `title`, `text`), `active_id`, `voice`, `rate`, `volume`, `auto_prepare`. Формат заметок в v7 не меняется, миграции не требуются.

Сохранение выполняется через временный файл `notes.json.tmp` и замену целевого файла. После изменения текста сохранение откладывается на 500 мс; при закрытии выполняется явно.

Готовые WAV и метаданные JSON находятся в `%APPDATA%\TellMe\audio`. Ключ кеша зависит от подготовленного текста и голоса. Метаданные могут содержать временные метки слов. Незавершённая запись не публикуется как готовая.

Для резервной копии заметок скопируйте `notes.json` при закрытом приложении. Кеш записей переносится отдельно. Два одновременно открытых экземпляра могут перезаписать заметки друг друга; перед запуском новой версии закройте старую.

# История изменений

## 13 октября 2026 — Git

- Проект подготовлен для репозитория `dmiittry/tell_me_app_desktop`, основная ветка `main`.
- Добавлены `.gitignore` и `.gitattributes`: сборки, окружение и локальные данные исключены; окончания строк скриптов Windows сохраняются как CRLF.

## v7 — 1 октября 2026

- Кнопки «Очистить», «Вставить», «Скопировать» для текста открытой заметки.
- Обработка сочетаний Ctrl по кодам клавиш Windows, независимо от раскладки.
- Вставка у курсора или вместо выделения, нормализация переводов строк и возврат из караоке к редактору.
- Вставка и очистка отделены в истории изменений; Ctrl+Z возвращает предыдущий текст.
- Пустой или недоступный буфер не удаляет выделение.
- Очистка останавливает озвучку этой заметки и отменяет отложенную подготовку даже при выключенной автоподготовке.
- Добавлены проверки редактора; общий набор содержит 31 тест.
- Скрипты запуска и сборки используют `.venv`, если оно существует; сборка называется `TellMe_v7.exe`.
